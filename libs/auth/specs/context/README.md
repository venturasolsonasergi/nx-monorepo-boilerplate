# Legacy Spec Context

This folder is retained for compatibility with the previous SDD workflow. New
behavioral requirements live in `openspec/specs/auth/<capability>/spec.md`, and
the HTTP contract remains `libs/auth/specs/openapi.yaml`.

The current OpenSpec workflows do not generate, overwrite, or consume files in
this folder. Record only behavior that is confirmed by implementation or tests;
do not invent a service context from placeholder files.
